ตัวอย่างจริง: restart service

👀 observe → "เช็คว่า service X down ไหม แล้ว restart ถ้า down"
🧭 plan → เรียก check_status ก่อน
⚡ act → check_status("service-x") → down
🧭 plan → เรียก restart_service
⚡ act → restart_service("service-x") → up
✅ plan → เสร็จแล้ว → ตอบ user

Chatbot ธรรมดา vs Agent

💬 Single-turnตอบครั้งเดียวจบ
🚫 ไม่มี toolไม่แตะโลกภายนอก
🙋 User ทำ step ต่อไปเอง
🕳️ ไม่มี state ระหว่าง turn
📚 เหมาะกับ Q&A / สรุปข้อความ
VS
🔁 Multi-turn tool useวน loop จนงานเสร็จ
🛠️ เรียก tool จริงไฟล์, API, terminal, DB
🤖 ทำหลายขั้นตอนอัตโนมัติ
💾 เก็บ context เพื่อวางแผนต่อ
🏗️ เหมาะกับงานที่ต้องลงมือทำจริง

ทำไมองค์กรต้องสนใจ

💼
Presale
research คู่แข่ง/ลูกค้า, draft proposal, สรุป requirement
👨‍💻
Engineering
เขียนโค้ด, debug, review PR, deploy, ลด manual toil

ตัวอย่างงานจริงที่ agent ช่วยได้

🐛
Engineer
หา bug ที่ทำให้ test fail แล้ว fix ให้
📝
Presale
สรุป pain point จาก transcript แล้วร่าง outline proposal
📊
Ops
ตรวจ log 24 ชม. หา anomaly แล้วสรุป report

จุดร่วม: หลายขั้นตอน ทำซ้ำได้ แต่ยังต้อง "ตัดสินใจ" ระหว่างทาง
