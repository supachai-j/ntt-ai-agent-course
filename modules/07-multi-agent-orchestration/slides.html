Claude Code Custom Subagents

สร้างเป็นไฟล์ Markdown + YAML frontmatter ใน .claude/agents/*.md

---
name: reviewer
description: Reviews code for security issues, bad practices, and style violations. Use proactively after writing or editing code.
model: sonnet
tools: Read, Grep, Glob
---

You are a senior security-focused code reviewer.
Review the diff or files given for:
- Injection risks (SQL, command, template)
- Secrets/credentials committed in plaintext
- Missing input validation
- Unsafe deserialization

Report findings as a list with severity (critical/high/medium/low),
file:line reference, and a concrete fix suggestion. Do not modify files.

เรียกใช้ Subagent: Static vs Dynamic

📄Static @name.claude/agents/*.md
→
⚙️Dynamic --agentsCLI flag, no file
› @reviewer check this diff for security issues
claude -p "review auth.py" \
  --agents '{"reviewer":{"description":"security reviewer","prompt":"You are a security reviewer...","tools":["Read","Grep"]}}'

Parallel Claude Instances ผ่าน tmux

รันหลาย independent task พร้อมกัน — แต่ละ task แยก tmux session

# สร้าง session แยกสำหรับแต่ละงาน
tmux new-session -d -s task-readme "claude -p 'write README.md for this repo' > out-readme.log"
tmux new-session -d -s task-tests  "claude -p 'write unit tests for utils.py' > out-tests.log"

# monitor ผลแบบ loop
for s in task-readme task-tests; do
  echo "=== $s ==="
  tmux capture-pane -t "$s" -p | tail -20
done

# เช็คว่า session จบหรือยัง แล้ว kill session ที่ค้าง
tmux list-sessions
tmux kill-session -t task-readme

⚠️ Anti-pattern: Dependency Race Condition

❌ อย่าทำรัน "เขียน endpoint" + "เขียน test เรียก endpoint" ขนานกัน
VS
✅ ทำแบบนี้Sequential: endpoint เสร็จก่อน → ค่อยเขียน test
Task B อาจ generate test ก่อน task A สร้าง endpoint จริง → test อ้าง signature ที่ยังไม่มี หรือ mock ผิดจากของจริง เฉพาะงานที่ independent จริง (ไม่ share state/interface) ถึงรันขนานได้

🔍 Second Look: Spawn Sub-Agents ให้ Deep Review

ก่อน commit งานสำคัญ — สั่ง main agent ให้ spawn sub-agents รีวิวทั้งโปรเจกต์แบบอิสระ ไม่ใช่แค่ diff เดียว

🛠️Main agent implement เสร็จcontext เต็มด้วย history การเขียนโค้ด
→
🧩Spawn sub-agents รีวิวcontext สะอาด เฉพาะงานรีวิว
→
📋Consolidated findingsกลับเข้า context หลักแค่สรุป
› Spawn several sub-agents to do a deep independent review of everything
  we just built in this project. Report back a consolidated list of findings.
💡 สอง benefit: (1) thinking space — sub-agent มี context ว่างเฉพาะรีวิว (2) รักษา context หลักไว้ — ได้แค่สรุป ไม่ใช่ full review pass · ที่มา: youtu.be/hy8UstR2NEg
