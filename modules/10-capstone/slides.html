Capstone = การรวมร่าง

โจทย์เดียว แต่ต้องเอาความรู้ทุก module มาใช้จริง — ไม่ใช่แค่เขียน prompt แล้วรอผล แต่ต้อง design, build, secure, test และ ship เป็น artifact ที่ demo ได้จริงในเวลาจำกัด

เลือกโจทย์ Capstone

เลือก use case จริงจากงาน NTT อย่างใดอย่างหนึ่ง (หรือเสนอโจทย์ของทีมตัวเองก็ได้ ถ้าใกล้เคียง scope นี้):

1. Presale Proposal Generator

Agent ที่รับ requirement ลูกค้า + template เดิม แล้ว draft proposal/SOW เบื้องต้น พร้อม citation จาก past project ที่เกี่ยวข้อง

2. Automated PR Reviewer สำหรับทีม

รัน Claude Code แบบ headless ใน CI เพื่อ review PR อัตโนมัติ — เช็ค coding standard, security pattern, และ comment กลับใน PR

3. Internal Doc / Runbook Agent

Agent ที่ค้นและตอบคำถามจาก internal doc/runbook (RAG หรือ MCP filesystem tool) พร้อมอ้างอิงแหล่งที่มาทุกครั้ง

4. Monitoring / Alert Agent

Agent ที่ตรวจ log/metric ผ่าน MCP tool แล้วสรุป incident, เสนอ root cause และแจ้งเตือนทีมผ่าน chat (Slack/Telegram)

Rubric การประเมิน

Functionality (30%)

Agent ทำงานได้จริงตาม spec ที่ตั้งไว้ — รันแล้วได้ output ที่ถูกต้อง ไม่ใช่ demo แบบ mock

Safety (25%)

มี hook/permission ครบตาม risk ของ use case — block destructive action, ไม่ leak secret, มี audit trail

Documentation (20%)

มี README.md และ CLAUDE.md ที่อธิบายชัดว่า agent ทำอะไร, setup ยังไง, limitation คืออะไร

Demo (25%)

Demo ได้จริงในเวลาจำกัด (5–10 นาที) — รันคำสั่งจริง ไม่ใช่ slide เล่าเฉย ๆ

Phase 1–2: Spec + Setup

1เขียน spec สั้น (1 หน้า) ก่อนเริ่มโค้ด:

## Problem
## Users
## Core loop (observe/plan/act/verify)
## Out of scope

2Setup project จริง:

mkdir capstone-agent && cd capstone-agent
git init
touch CLAUDE.md README.md
mkdir -p .claude
# settings.json ใส่ permissions/hooks

Phase 3–4: Build Core Loop + Hook

3ใช้ Claude Code จริงสร้าง core feature:

claude -p "implement the core agentic loop
described in spec.md, write tests" \
  --allowedTools "Edit,Bash(git *),Write"

4เพิ่ม PreToolUse hook กัน risk:

{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "./.claude/hooks/block-danger.sh"
      }]
    }]
  }
}

Phase 5–6: Test + Deploy/Demo

5Test + capture evidence จริง:

pytest -v | tee test-output.log
git add -A && git commit -m "capstone: tested core loop"

6เขียน README พร้อม output จริง แล้ว demo:

## Usage
\`\`\`
$ python agent.py "review this PR"
[actual output pasted here]
\`\`\`
