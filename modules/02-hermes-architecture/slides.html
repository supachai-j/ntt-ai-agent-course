Profiles: แยก workspace ต่อบริบท

Path convention

/home/ubuntu/.hermes/profiles/<name>/
  ├── skills/
  ├── memories/
  ├── cron/
  └── plugins/ (ถ้ามี)

# default profile:
/home/ubuntu/.hermes/skills/

Terminology: 5 คำที่สับสนกันบ่อย

คำความหมาย
Profilepersistent home directory ของ assistant หนึ่งตัว
Agentrunning instance ที่ใช้ profile นั้นอยู่
Botprofile ที่ present เป็น roster ใน Bot Mode
Platform accountaccount จริงบน Telegram/Discord ที่ผูก gateway
Subagentchild assistant จาก delegate_task
⚠️ Official safety warning: "Never point two agent processes at the same profile" — สองตัวเขียน memory ชนกันจนสถานะพัง

name: my-skill-name

version: 1.0
---

## When to use
## Steps
## Pitfalls

Skills: linked_files & keyword trigger

linked_files structure

my-skill/
  SKILL.md
  references/   # เอกสารอ้างอิงยาว
  templates/    # ไฟล์ template ให้ copy
  scripts/      # helper scripts
Write lessons, not logs: imperative rule + เหตุผล ไม่ใช่ log เหตุการณ์

Subagent Orchestration: delegate_task

🔒
Isolated context
ไม่เห็น conversation หลักของ parent
📦
Parent ต้องใส่ context เอง
path, spec, constraints ครบ
🗣️
Self-report
ผลลัพธ์คือข้อความบรรยาย
⚠️ อย่าเชื่อ self-report เฉยๆ: ต้อง verify ด้วย evidence จริง — read_file, เช็ค URL, รัน command

ตัวอย่าง delegate_task ในทางปฏิบัติ

delegate_task({
  task: "Build slides.html และ lab.html สำหรับ module 02 ...",
  context: "spec เต็ม + content brief + path ที่ต้องใช้ ...",
})

// หลัง subagent รายงานว่า "ทำเสร็จแล้ว":
// → parent ต้อง read_file / ls -la ยืนยันเองเสมอ
